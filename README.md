Milly John’s Burgers Website

Project Overview

Milly John’s Burgers is a responsive restaurant website developed using HTML5 and CSS3. The website was designed to showcase a fictional fast-food restaurant that sells burgers, wings, desserts, beverages and breakfast meals.

The website focuses on modern web design principles including responsive layouts, user-friendly navigation, interactive elements and visually appealing content presentation.

⸻

Features

* Responsive website design
* Interactive navigation menu
* Multiple food and beverage pages
* Featured meals section
* Hover animations and transitions
* Mobile-friendly layouts
* Styled buttons and cards
* Organized page structure
* External CSS styling
* Modern typography using Google Fonts
